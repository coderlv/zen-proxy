# zen-proxy

Прокси между агентскими CLI (ZCode, Claude Code, opencode) и free-тарифом opencode
(`https://opencode.ai/inference/openai/v1`). Один файл `zen-proxy.mjs`, без зависимостей.
Живой сервер владельца: `127.0.0.1:8787` (`node zen-proxy.mjs`) — **не рестартовать и не
убивать**, конфиг подхватывается автоматически.

## Эксплуатация

- Конфиг: `~/.config/zen-proxy/zen-proxy.json`. Живой сервер слушает его через `fs.watch`
  и hot-reload'ит сам (≈150 мс) — правки применяются без рестарта.
- HTTP из скриптов делать node/bun-файлом (хук блокирует inline-fetch/curl).
- Тестовые копии поднимать только с временным конфигом (`port` в конфиге перекрывает `PORT`):
  `ZEN_PROXY_CONFIG=/tmp/x/cfg.json ZEN_PROXY_STATS=/tmp/x/stats.json node zen-proxy.mjs`.
- Дашборд/API: `/api/status`, `/api/logs`, `/api/proxies`, `/api/analytics`.

## Гейт free-тарифа opencode

Гейт периодически меняется (10-24 → 10-30 → 11-01 день/вечер) — при всплеске 429 сначала
заново снимать байты и бисектить, не доверять старым выводам. Известные классы (обе проверки
работают одновременно): в `tools[]` нужен инструмент с именем строго `read` (zen-proxy
`agentTools: true` дописывает read-stub — не выключать), и гейт **считает узнаваемые
harness-имена** tools[]: ≥29 узнаваемых → 429 (неузнаваемые не в счёт). zen-proxy ужимает
хвост свыше 27 имён вызывающего до синтетических `tN` (`gateNameTools`) и разворачивает их
в ответе через `back`.

- TLS-hello, UA, session/project-заголовки, формат env-блока, exit-IP — НЕ рычаги
  (доказано реплеем захваченных байтов 2026-11-01, HANDOFF §8.10).
- «Постоянный 429» — чаще всего оконная квота на exit-IP: вердикты гейта флапают от
  минуты к минуте, одиночные проверки лгут. Метод: интерлив-бисект с контролем
  (идентичный запрос) в каждом раунде, 5–7 повторов на вариант.
- Снимать точные байты egress: тест-инстанс с `upstream: http://127.0.0.1:<port>` +
  локальный capture-listener, реплей через Bun `fetch` c опцией `proxy`.
- Ретраи множат сжигание квоты: `retriesPerModel` держать 0 (opencode шлёт один запрос).
- Долгосрочный путь от квоты: `defaultZenKey` или Go (`/inference/go/openai/v1`).
